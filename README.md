# NOVA-STUDENT-PHEONIX


NOVA Your Focus. Your Future.

About NOVA

NOVA is an AI-powered student productivity platform designed to bring learning, organisation, focus and motivation together in one place. It aims to simplify the student experience by providing a centralised environment where students can manage their academic activities, access learning resources, organise their study schedules and monitor their progress.

Problem Statement

Students today rely on multiple applications to manage their academic responsibilities, access educational resources and maintain productivity. Constantly switching between platforms, dealing with digital distractions and struggling to maintain consistent study habits can make effective learning more challenging. NOVA aims to address these challenges through a unified student-focused productivity platform.

Our Solution

NOVA provides an integrated platform that brings essential student productivity tools together. Through its dashboard, students can organise their daily activities, manage upcoming deadlines, plan study sessions and monitor their progress. The platform aims to create a more organised, accessible and focused learning experience.

Key Features

NOVA includes a Smart Student Dashboard that provides an overview of student activities, a Study Planner for organising schedules and deadlines, and an AI Study Assistant designed to support learning and doubt clarification. Its Distraction-Free Learning experience aims to help students discover educational videos in a focused environment. Additional productivity features include focus tools, streaks and progress tracking, study challenges and Study Partners that allow students to connect with friends and encourage accountability.

Technology Stack

The current prototype uses HTML, CSS and JavaScript, with Tailwind CSS for styling. The project is designed as a web-based student productivity platform.

How to Run the Prototype

To explore the NOVA prototype, download the repository or clone it to your computer. Locate the file named "nova_student_productivity_platform.html" and open it using a modern web browser. An internet connection may be required for externally loaded libraries and resources.

Our Vision

Our vision is to create a smarter, more connected and productive learning environment where students can spend less time switching between applications and more time focusing on their goals. NOVA aims to encourage better learning habits, consistent progress and collaborative motivation.
